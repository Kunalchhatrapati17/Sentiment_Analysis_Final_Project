# Real-Time Stock Market Data Analysts with Sentiment Analysis
# Introduction:-
In this project, i have created End-to-End Data Engineering project on Real-Time Stock Market Data Analysis using Kakfa through Sentiment Analysis

We are going to use different Technologies such as Python, Amazon Web Services(AWS), Apache Kafka, Glue, Atherna, Crawler, Excel and SQL, Pyspark.
